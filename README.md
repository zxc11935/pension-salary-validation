# pension-salary-validation (개인 프로젝트)
연봉은 취업 준비생, 이직 준비생, 현직자 모두가 궁금해하지만 묻기도 말하기도 조심스러운 정보입니다. 그래서 많은 사람이 취업 플랫폼에 올라온 '국민연금 기준 평균 연봉'을 참고합니다. 그런데 이 숫자는 실제와 얼마나 맞을까요? 이 프로젝트는 국민연금 사업장 데이터로 회사별 평균 연봉을 직접 추정하고, 상장사가 사업보고서에 공시한 1인 평균 급여액과 대조해 추정이 얼마나, 어떤 회사에서 틀리는지 확인합니다. 개인이 아닌 회사 단위 평균만 다루며, 취업 준비생과 이직자가 이 숫자를 어디까지 믿어도 되는지 판단할 기준을 만드는 것이 목표입니다.
