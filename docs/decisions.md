# 결정 기록

## 2026-10-07 · 주제 결정
- 결정: 국민연금 사업장 데이터로 추정한 연봉을 DART 공시 '1인 평균 급여액'과 대조해 오차를 검증한다
- 고른 이유: 실제 공개 데이터 / 대조할 기준(상장사 공시 1인 평균 급여액)이 있음 / 검증할 함정이 이미 확인됨(사업자번호 앞 6자리만 공개, 보험료율 연도별 변경, 소득 상한, 신고 시차)
- 안 고른 후보: OpenDART 재무제표(이미 많이 다뤄진 주제, 전환 후보로 유지), 나라장터 공공 IT 계약(공공조달 구조를 처음부터 익혀야 해 부담이 가장 큼), 주가 검증·실거래가(이미 많이 다뤄진 주제)
- 전환 조건: 1단계 표본 상장사 20곳 중 한 사업장에 정확히 붙는 회사가 15곳 미만이면 OpenDART 재무제표로 전환
- 바뀐 판단: '국민연금으로 연봉을 추정할 수 있다'가 아니라 '그렇게 추정한 연봉을 얼마나 믿어도 되나'를 묻는 프로젝트로 질문을 바꿈 (국민연금 기준 평균 연봉은 취업 플랫폼에서 이미 보여주고 있음)

## 2026-10-07 · 수집 코드와 원본 폴더를 출처별로 분리
- 결정: 수집 코드를 collect_dart.py · collect_nps.py로, 
원본 폴더를 data/raw/dart · data/raw/nps로 나눈다. load.py는 하나로 유지.
- 고른 이유: 두 API는 인증키를 넣는 방식과 호출 한도가 따로라, 
한쪽 오류가 다른 쪽 수집까지 멈추지 않게 하기 위함.
넣는 곳(DB)은 하나라 load.py는 나누지 않음
